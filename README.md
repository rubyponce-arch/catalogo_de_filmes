## Projeto Catálogo de Filmes

**RF01**

O sistema deve permitir que o usuário **acesse sua conta** utilizando login e senha.

**RF02**

O sistema deve permitir que o usuário **cadastre filmes**, informando:

-   Nome do filme
-   Ano de lançamento
-   Gênero
-   Nota de 0 a 10
-   Imagem da capa

**RF03**

O sistema deve permitir que o usuário **visualize sua coleção de filmes** cadastrados.

**RF04**

O sistema deve exibir a **imagem da capa** de cada filme cadastrado.

**RF05**

O sistema deve permitir que o usuário **visualize as informações** de cada filme cadastrado.

**RF06**

O sistema deve permitir que o usuário **edite as informações** de um filme já cadastrado.

**RF07**

O sistema deve permitir que o usuário **altere a imagem da capa** de um filme cadastrado.

**RF08**

O sistema deve permitir que o usuário **exclua filmes** de sua coleção.

**RF09**

O sistema deve solicitar uma **confirmação antes da exclusão** de um filme.

**RF10**

O sistema deve permitir que o usuário **encerre sua sessão**.

----------

## Requisitos Não Funcionais

**RNF01**

O sistema deve possuir **autenticação segura**, protegendo o acesso à coleção de filmes.

**RNF02**

O sistema deve garantir a **privacidade dos dados**, permitindo que somente o usuário autorizado acesse sua coleção.

**RNF03**

O sistema deve possuir uma **interface simples e intuitiva**, facilitando o cadastro, edição, visualização e exclusão dos filmes.

**RNF04**

O sistema deve apresentar os filmes em uma **interface visual organizada**, destacando as imagens das capas.

**RNF05**

O sistema deve ser **responsivo**, permitindo sua utilização em computadores, tablets e smartphones.

**RNF06**

O sistema deve realizar as operações de cadastro, edição, consulta e exclusão com **tempo de resposta adequado**.

**RNF07**

O sistema deve garantir a **integridade dos dados** armazenados.

**RNF08**

O sistema deve realizar a **validação dos dados informados** pelo usuário.

**RNF09**

O sistema deve permitir o armazenamento e a exibição das **imagens das capas dos filmes**.

**RNF10**

O sistema deve ser compatível com os **principais navegadores atuais**, como Google Chrome, Mozilla Firefox, Microsoft Edge e Safari.
